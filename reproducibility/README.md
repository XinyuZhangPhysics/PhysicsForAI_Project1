# Public reproducibility layer

This directory contains project-owned provenance and frozen numerical summaries for analysis families retained in *Expert-Specific Response in Mixture-of-Experts*.

- `core_results.tsv`: retained headline numerical summaries.
- `claim_to_source.tsv`: active manuscript analyses mapped to retained public source groups.
- `frozen_assets.tsv`: retained revisions/protocol/package hashes.
- `statistical_design.tsv`: sampling and uncertainty semantics.
- `postpaper_E1_E4.tsv` and `postpaper_protocols.tsv`: retained E1 and E4a/E4b records only.

The fixed-routing OLMoE, native trained-MoE tomography/objective-response, signed-descent E2, and utility E3 programs are outside the active manuscript and have been withdrawn from the current branch.

The 2026-10-27 generic non-mode-aligned local-dynamics numerical record is preserved in the scientific archive. Its exact historically executed model-facing source remains pending public recovery; it is not reconstructed here.
