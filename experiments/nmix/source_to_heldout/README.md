# Source-to-heldout mixed-Hessian experiment

This experiment measures the restricted 12-dimensional Hessian on source Bank A and predicts nonlinear gradient increments on disjoint Bank B.

The public directory contains the executed evaluator source, the exact coordinate/bank identities, compact Bank-B states and responses, and the measured source Hessian. The verifier reconstructs the normalized full-Hessian and mixed-block-deleted residuals directly from these artifacts.

The experiment uses the model, objective, bank and coordinate conventions in `../common/config.json`.
