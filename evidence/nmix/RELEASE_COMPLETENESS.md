## Required before this branch can replace `main`

The final revision-4 result bundle contains the exact executed production source, frozen contrast/direction arrays, 72 signed Bank-B state outputs, raw/symmetrized Bank-A Hessian, support diagnostics, and all 10,000 paired bootstrap replicates. Those bytes are retained in the project archive but are not currently exportable through the available Project Library interface in this synchronization session.

Therefore this branch is a **public synchronization candidate, not yet the final reproducibility release**. Do not use it to assert that the manuscript's unchanged Data Availability statement has been fully verified. Before fast-forwarding `main`, publish a public-safe subset sufficient to reconstruct the primary statistics from model-facing outputs: at minimum the exact production source/config, frozen contrast/direction arrays, and compact per-direction sufficient statistics (or equivalent raw gradient/Hessian arrays), together with their source hashes.

Raw copyrighted token-bank contents, model weights, unnecessary caches, and full-state captures should remain excluded.
