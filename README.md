# PhysicsForAI Project 1 — source and reproducibility release

Code and project-owned reproducibility material accompanying *Expert-Specific Response in Mixture-of-Experts*.

The public tree is synchronized to the active manuscript. It contains the retained copied-state sector-selection, full-tangent, expert-side, background-conversion, duplication-state local-dynamics, and finite-time analysis families. Experiment families removed from the manuscript remain outside the active scope.

## Reproducing the model-facing experiments

All project-owned information required to reconstruct the reported experimental inputs is public. Exact S1/S2 corpus row identities, hashes, pair-selection seeds, training-seed manifests, protocol metadata, and pinned upstream revisions are under `reproducibility/upstream_selection/`; the reconstruction workflow is documented in `reproducibility/UPSTREAM_RECONSTRUCTION.md`.

Third-party weights and corpus text are not redistributed. Readers obtain the pinned Pythia-70M, SmolLM2-135M, and SlimPajama-6B revisions recorded in `configs/models.json`. Project-owned token banks, representation captures, F0 arrays, mixed operators/spectra, checkpoints, and trajectory tables are reproducible intermediate outputs generated by the public source and are not an additional private data dependency.

## Evidence identity

The growth figure preserves the 11-cell P2J primary aggregate and the separately frozen P2L confirmation; P2L is never substituted into the primary aggregate. The stationary-background common-absolute-`lambda` record labels nonzero-background values at `lambda=lambda_c(0)` as theory-only references, not measured trajectories.
