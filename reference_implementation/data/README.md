# Frozen derived inputs

Project-owned numerical arrays and sufficient statistics, under CC BY 4.0.
CSV column names retain the measured quantity definitions. NLL arrays contain
no text, token arrays or document IDs. Their aligned positions preserve paired sampling.
Aggregate native NPZ files retain only 6x6 matrices. Formation spectrum retains
numerical singular vectors and singular values. Original container hashes and
execution source hashes are provenance references; rebuilt compact containers
have new public checksums. See DATA_DICTIONARY.md and docs/DATA_PROVENANCE.md.
