# Reproducibility — active manuscript scope

1. Run data-independent operator tests with `python -m unittest discover -s tests -v`.
2. Download the pinned third-party models/corpus listed in `configs/models.json`.
3. Verify/reconstruct the exact upstream samples using `reproducibility/upstream_selection/`, `reproducibility/verify_upstream_manifests.py`, and `reproducibility/UPSTREAM_RECONSTRUCTION.md`.
4. Use the repository-level `experiments/` source groups and `PUBLIC_SOURCE_BINDINGS.tsv` for retained historical model-facing execution source.
5. Use `reproducibility/` and `evidence/` for frozen summaries, hashes, statistical-unit semantics, and cross-checks.

No additional project-owned scientific input is required from the author; large intermediate arrays and trajectories are regenerated by the public pipeline from the pinned upstream assets.
