# Data provenance and public boundary

The current GitHub release is source-only and does not bundle project-owned experimental outputs or intermediate scientific captures.

The private research archive retains the raw and derived assets used in the study together with source hashes, run seals, and experiment records. Project-owned numerical outputs needed for paper-level reconstruction may be provided by the author on reasonable request. Third-party model weights, corpora, and other licensed assets are not redistributed and must be obtained from their original providers.

The public repository preserves sanitized historical source snapshots, clean reference implementations, configuration/environment information, tests, and provenance mappings. Code/documentation are MIT licensed; upstream assets retain their original licenses.
