# Data provenance and public boundary

The public repository contains the source code, fixed seeds, protocols/configuration, project-owned sample-identity manifests, hashes, pair-selection seeds, and compact evidence required to reconstruct the active manuscript experiments.

Third-party model weights and SlimPajama corpus text are not redistributed; they must be obtained from their original providers at the pinned revisions recorded in the repository. The published row identities and SHA-256 values allow those upstream samples to be independently verified.

Large arrays, token tensors, representation captures, mixed operators/spectra, checkpoints, and full trajectory tables are generated intermediate products of the public pipeline. They are not an additional project-owned data dependency.

See `reproducibility/UPSTREAM_RECONSTRUCTION.md`.
