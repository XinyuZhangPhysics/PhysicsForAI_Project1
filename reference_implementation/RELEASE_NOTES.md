# v1.0.0

Code and derived data accompanying "From Symmetry to Response: Expert-Private Response Channels in Mixture-of-Experts". This release maps the existing frozen-output reconstruction to the exact delivered v318 manuscript and supplement. It includes clean operator implementations, compact numerical inputs, tests, expected hashes, experiment and result maps. It does not claim that the manuscript is published, that a DOI exists, or that public scripts perform full historical model-facing reruns. Model weights, corpus content, raw scientific captures and private execution code are excluded.
